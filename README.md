# ASM Shield — Attack Surface Management Dashboard

[![Vite](https://img.shields.io/badge/Vite-8.2-purple.svg)](https://vitejs.dev/)
[![React](https://img.shields.io/badge/React-19.2-blue.svg)](https://react.dev/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

An enterprise-grade, real-time cybersecurity Attack Surface Management (ASM) dashboard built with React 19, Vite 8, Recharts, and Lucide React. Designed with a deep navy cybersecurity aesthetic, vibrant data visualizations, micro-interactions, dark/light theme options, and modular architecture.

---

## 🚀 Features

- **Dashboard & KPIs**: Overview of total assets, surface health score, critical flaws, active threat vectors, and risk telemetry graphs.
- **Assets Inventory**: Interactive cloud infrastructure inventory with risk levels, port mapping, and live telemetry details.
- **Vulnerability Management**: Prioritized CVE tracking table with CVSS scores, status tracking, and remediation drawer.
- **Threat Intelligence Feed**: Live threat feed tracking active exploits, threat actor campaigns, and EPSS scores.
- **Subdomain Reconnaissance**: Passive DNS and subdomain enumeration tool with dangling CNAME takeover alerts.
- **Security Incident Logs**: Real-time event syslog inspector with IP isolation playbook actions.
- **Export Engine**: Flexible reporting engine with CSV, JSON, and PDF download triggers.
- **Multi-Theme Support**: Dark (cyber navy default), Light, and Deep Blue Matrix theme modes.

---

## 🛠 Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite 8
- **Styling**: Vanilla CSS (CSS Variables, Flexbox/Grid, Dark Mode)
- **Charts**: Recharts
- **Icons**: Lucide React

## 📦 Installation & Setup

```bash
# Clone the repository
git clone https://github.com/kuntal0903/resolve-frontend.git
cd resolve-frontend

# Install dependencies
npm install

# Start local development server
npm run dev
```

Server will start locally at `http://localhost:5173/`.
